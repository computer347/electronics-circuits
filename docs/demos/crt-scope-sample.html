What it is: an oscilloscope. It draws voltage (up/down) against time (left/right). The grid is the graticule: 10×8 divisions, each worth the V/div and time/div shown in the corners. Drag the knobs (or use arrow keys) to change the scale; pick a signal to see it redraw.
Effects: sweeping beam with phosphor afterglow, glow on the trace, scanlines, glass vignette, slight flicker.
